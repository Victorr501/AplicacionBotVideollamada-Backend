# AplicacionBotVideollamada-Backend

Este repositorio es la aplicacion backend de una pagina web que envia la un bot a una videollamada con un enlace y este una vez dentro de la videollamda copila la informacion y documenta la reunion.
Esta hecho en Python con el framework FASTAPI

## Documentacion

La documentacion esta en [notion](https://app.notion.com/p/Plan-de-desarrollo-3d0d519f81c28034ad50f2ddd7ae4371)

## Desplegar servidor

Para desplegar el servidor de FASTAPI, lo primero tienes que estar en la carpeta src y ejecutar el siguiente comando en la terminal:

'''markdown
uvicorn main:app --reload
'''
